# Streamcore zum Herunterladen

- **Mac:** [Streamcore-Mac.dmg](https://github.com/synqberlin/streamcore-downloads/raw/main/Streamcore-Mac.dmg)
  DMG öffnen, Streamcore auf „Programme“ ziehen, dann einmal im Terminal:
  `xattr -cr /Applications/Streamcore.app`

- **Fire TV:** in der App „Downloader“ diese Adresse eintippen:
  `github.com/synqberlin/streamcore-downloads/raw/main/tv.apk`

Server bei der Anmeldung mit `http://` eintragen.
